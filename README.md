# Notenlernen

Kostenloser, werbefreier Noten- und Intervalltrainer als responsive Offline-PWA für Smartphone, Tablet und PC. Keine Konten, keine Cloud, keine Trainingsdatenübertragung.

Zieladresse: https://notenlernen.github.io/

## Status
Planungsphase abgeschlossen; M0 steht zur Implementierung an. Noch keine veröffentlichte Anwendung.

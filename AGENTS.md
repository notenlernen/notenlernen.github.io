# Entwicklungsregeln
Verbindliche Spezifikation: docs/REQUIREMENTS.md, ARCHITECTURE.md, ROADMAP.md, TEST_STRATEGY.md, DECISIONS.md. Abweichungen dokumentieren und bei fachlichen Änderungen Freigabe einholen. Feature-Branch je Meilenstein, kein eigenmächtiger Merge. Keine Geheimnisse, personenbezogenen Daten oder nicht lizenzierte Assets committen. Tests lokal ausführen, CI-Ergebnisse prüfen, tatsächliche Resultate und Blocker im PR dokumentieren. Keine erfundenen Testresultate. Lockfile pflegen, Version/Changelog aktualisieren. Keine Cloud- oder Tracking-Abhängigkeiten. Datenverlust durch Updates verhindern.
